# Changelog

## 0.1.0

First version.

- Meal plans of all Studentenwerk Halle canteens from meine-mensa.de, today and the next five days
- Canteens chosen during setup, changeable with Reconfigure; one sensor per canteen
- Dashboard card served by the integration itself, no resource to add
- Filter for vegetarian and vegan meals, as a setting and as buttons in the card
- Hide meals by word, e.g. an allergen; photos, sides, labels, allergens and prices can be switched on and off
- Day: next day with meals, tomorrow, today, or today until a set time and then the next day
